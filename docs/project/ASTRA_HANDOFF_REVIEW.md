# Проверка двух комплектов Астры от 13 ноября 2026

Исходный кандидат для сдачи: коммит `5d7705831c310f5a1eaf43d901bf0918983e5fec`,
стратегия Docker `empirical_hybrid`. Его сборка и офлайн-проверка прошли в
GitHub Actions: запуски 43477106909 и 43477107318.

Оба полученных архива распакованы в отдельные каталоги после проверки путей,
символических ссылок, количества файлов и распакованного размера. Вложения не
выполнялись. `openjiuwen_submission_ready.zip` имеет локальный SHA
`376bfe126e3ecf051052a53207e704eb80229e33` и рекомендует `baseline`;
`openjiuwen_submission.zip` имеет локальный SHA
`473d9c0bdbdbc7bcfb693ed95b6da12d4ed1c32c` и рекомендует
`stat_budget_slow`. Оба исходят из более раннего снимка, поэтому полная замена
убирает проверенные `empirical_hybrid`, строгий учёт неопределённых вызовов,
журнал запросов, вложенные лимиты, тесты жизненного цикла и конкурсный workflow.

Mock-проценты из отчётов описывают синтетическое распределение. На настоящем
Qwen и официальном наборе преимущество новых стратегий не проверено.
Сквозные панели не дали выигрыша по reward. Поэтому стратегия и команды
запуска текущего кандидата не переключаются.

Перенесены только изолированные исправления: `fsync` до атомарной замены
`answer.txt`; перенос `finish_reason` от провайдера к решателям и отклонение
ответа при `length`; преобразование словаря аргументов инструмента SDK в JSON;
очистка частичного списка схем при отказе обёртки SDK. Повторы неясных запросов
и raw fallback после уже отправленного запроса не переносились.

Локально прошли 28 целевых тестов, включая шесть новых регрессионных.
Полный набор в текущем ограниченном окружении не завершился; тесты, которым
нужен локальный TCP-сокет, получают `PermissionError`. Docker здесь отсутствует.
Перед включением в финальный `main` нужны CI и сборка образа именно этого
кандидата. Эти ограничения относятся к данному переносу и не отменяют
ранее прошедшие проверки исходного коммита.
